# 美德 · 自由（LIBERTAS · FREEDOM）—— 被锁住的自由女神像 → 举起火炬的金色女神

照「诚实」「自律」的两幕反转结构做的单支，25.2 秒，1920×1080 30fps，无配音。**画面上不出现“七美德”**：
标签是「美德 · 心无枷锁」，光环刻字 `LIBERTAS INAESTIMABILIS RES EST · LIBERTAS`（自由是无价之物，罗马法谚）。
人物按主题设计：**自由女神像**（用户点名），转场用金光斜斩，**斩断锁链**。

每群白鸽的振翅扑棱；C 大调和弦与和声、钟声、慢鼓、光波轻响。响度 −16 LUFS。

## 代码（`src/`）

引擎沿用 `2026-10-22_virtue-discipline/src/`（`index.html`、`fx.js`、`render.js`、`build.sh` 未改），这次新增：

- `figures/liberty.js`：本片人物——侧脸（希腊式直鼻）、往后梳的波浪发 + 发髻、带窗格的冠带和七道光芒、斜披的长袍、铭牌；
  手臂按骨骼画（上臂 / 前臂局部坐标 → 画面坐标），宽袖按重力从手臂下侧垂下；火炬（握柄、杯、围栏）沿前臂方向，火焰永远朝上；
  锁链按折线一节节排链环（正面环 / 侧面环交替），斩断时刻用链子和 `SLASH` 求交、按斜斩缓动反推 `tc`，崩散的链环在加载时算好初速度；
  举起火炬的轨迹（`armPose`）、点燃（`TI`）、光芒亮起（`RAY0 / RAY_DT`）、放飞白鸽（`FLOCKS`）都是时间常量，改节奏只动它们；
  人物整体缩 0.9 倍（`FS / FO`），火炬才不会顶出画面；斜斩求交、白鸽、光晕用 `toScr` 换到画面坐标
- `gen_stories.py`：全部文案 → `stories/freedom.js`
- `audio.py`：新增人物音效 `clank / rattle / snap / chainfall / rise / ignite / ray / fire / wings`；`add()` 的声像夹在 [-1, 1]

重新出片：在 `src/` 下 `python3 gen_stories.py`，再在本目录 `bash src/build.sh freedom .`（4 核约 3 分钟）。
静帧预览：`NODE_PATH=$(npm root -g) VIRTUE=freedom node src/render.js still out 3 7.5 9.15 9.8 10.4 10.8 11.6 16.4`。

字体不入库：`npm pack @expo-google-fonts/noto-serif-sc @expo-google-fonts/noto-sans-sc @expo-google-fonts/cinzel`，
把 NotoSerifSC_900Black / NotoSerifSC_700Bold / NotoSansSC_700Bold / NotoSansSC_400Regular / Cinzel_400Regular / Cinzel_700Bold 放进 `src/fonts/`。
