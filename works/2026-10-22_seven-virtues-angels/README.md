# 七美德 · 天使篇（贞洁、慷慨、勤勉、忍耐、宽容、谦卑）

"七美德对七宗罪"版本，编号按传统顺序（之二「节制」见 `../2026-10-21_seven-virtues-temperance/`）。
结构同前两批（25.2 秒，1920×1080 30fps），人像换成天使，特效加强：

- **第一幕（罪）**：红色堕天使——残缺抖动的红翼；推送卡片 + 漂浮红字；上升余烬；画面撕裂（切片错位 + 红青色线）；
  心跳同步的红色暗角脉冲；扫描线；人像周围逐条亮起的红色裂纹。
- **转场**：去色 → 金光斜斩 → 闪白 → 罪字碎片 + 羽毛爆散 + 三重冲击波 + 镜头光晕。
- **第二幕（德）**：金色天使双翼从收拢到展开、缓慢扇动；头顶光圈；上帝光；环绕光点；持续飘落的发光羽毛；
  标题落下迸出光点 + 横向光晕。
