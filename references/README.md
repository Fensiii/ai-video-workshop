## 各类风格要点（复刻时先读）

### 1. 数据历史走势 `data-history/`
详见 skill `data-history-video`。透视倾斜图表、红绿光柱、发光曲线头、事件卡片、章节大标题、
底部迷你时间轴；事件前减速。抖音竖版画布，裁 `crop=1920:1080:0:1240` 得到 16:9 画面。

### 2. 歌词动画 MV `lyric-mv/`
- 一句歌词一个画面，画面内容直接图解歌词（下雨 → 撑伞，烟花 → 烟花，时差 → 日夜分屏）。
- `square-couple-planet`：扁平矢量卡通，角色是简单几何体（方块身体 + 表情），
  场景固定在一个小星球弧面上，背景只换色调和天气；歌词放在底部深色圆角条里，金色楷体。
- `paper-puzzle-collage`：纸张纹理、撕边贴纸、拼图块作为贯穿意象；歌词逐字放在小纸片上依次弹出，
  关键词放大变色（如“爱炙热的你”红字）。
- 适合做法：skia 或 HTML/Canvas 画矢量角色；时间轴严格对齐歌词 LRC。

### 3. 知识科普·暗金风 `knowledge-explainer/dark-gold/`
同一作者（Iwanau）的系列，视觉语言高度一致，可当一套模板：
- 黑底 + 暖金色光斑/暗角，衬线中文字幕居中偏下，关键词金色或红色高亮。
- 左上角“年份 + 地点/人物”小标；右上角论文/书名卡片（英文原名 + 中文名 + 红色小印章）。
- 道具感图形：泛黄档案卡、急诊记录、实验记录、论文封面、红色印章“出院/没有记录”。
- 极简白色人物剪影、线框飞机/图表，数据用细线图 + 金色标注。
- 结构：反常识钩子开场 → 历史实验/故事 → 原理解释 → 生活中的例子 → 金句收尾 → 片尾大标题（如“知识诅咒”“运气的形状”）。
- 适合做法：HTML/Canvas + Playwright（字幕和卡片多），参考 `tesla-success` 项目的 `【】/〔〕` 高亮字幕方案。

### 4. 知识科普·卡通夜景风 `knowledge-explainer/cartoon-night/`
- 深蓝夜空 + 月亮 + 银河，Q 版古风人物，左右两列对阵，用红色曲线连线演示算法每一轮。
- 顶部胶囊标题标“第几次·谁先开口”，配轮次计数；章节转场用大号书法字。
- 适合讲算法、博弈、匹配类过程：同一组元素反复重排，观众看连线变化理解规则。

### 5. 哲思极简 `philosophy-minimal/`
- `entropy-particles`：粒子系统讲概念（粒子散开=混乱、点阵组成人像=有序），
  单个大字金句居中（“疏远。”“混乱，是宇宙的默认设置。”），冷暖两色发光点。
- `nihilism-line-art`：黑底白色虚线/点线手绘，形象逐笔画出或由点汇聚，文字也会变成线条元素；
  结尾一抹金色日出收束。左上角章节名小字。
- 节奏慢、留白多，音乐氛围化。适合 skia 粒子/路径动画。

### 6. 七美德短片 `virtue-shorts/`
- 25 秒一支，两幕反转：**红黑"罪"**（评论卡片/弹幕层层堆满、漂浮红字、单个大字旋转，文字填充的侧脸人像 + 红光环 + 头顶火焰，
  镜头渐晃）→ 约 9s 去色 + 金光斜斩 + 闪白 → 碎成金片 → **金色"德"**（线描金边人像、光环刻七美德拉丁名、放射光线、顶部光柱）。
- 标题卡在左：细框标签「七美德 · 之一」、设问句（关键词用「」金字）、超大金色渐变衬线标题、斜体拉丁字母间距拉开。
- 配乐鼓点很重、全程有节拍。做法见 `works/2026-10-21_seven-virtues-temperance/`（HTML Canvas + Playwright）。

## 存放规则

- 新参考素材统一放这里，按类型建子目录；文件名用英文短横线描述内容。
- 每个视频都配一张同名 `.jpg` 缩略拼图，并在上表补一行。
- 单文件不超过 100MB；超过就压缩或只存链接。
