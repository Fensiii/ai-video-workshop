# 成品视频库

每一支做完交付的最终视频都存在这里，一个作品一个目录：`works/<日期>_<英文短名>/`。
目录里放成片 `.mp4`、缩略拼图 `thumbs.jpg`（全片均匀 12 帧），以及字幕、生成脚本等配套文件。

## 存放规则

- 每次交付最终视频时同步存入，并在上表加一行；改版就覆盖同一目录里的成片并更新说明。
- 单文件不能超过 100MB（GitHub 上限），超了用两遍编码压到约 90MB 以内。
