# 美德短片（两幕反转）

## 一、先定下来的默认值

- **25.2 秒、1920×1080、30fps**，无配音，配乐与音效全部 numpy 合成，响度 −16 LUFS。
- 用户没要求系列标签时，**画面上不写“七美德”**（标签、光环刻字、文案、话题都不写）。
  标签写成「美德 · <一句主题短语>」，光环刻一句与主题相关的拉丁文。
- **人物按主题设计，不要每次都用天使**（用户明确说过）。天使翅膀、女神面纱、头顶光圈这一套已经用过很多次，别再拿来顶。

## 二、结构与时间轴（所有主题通用）

| 时间 | 第一幕：罪（红黑） | 声音 |
|---|---|---|
| 0–4.6s | 黑暗里先亮起人物的一只眼 / 一个标志物；推送卡片一张张弹出，红字漂浮 | 低频嗡鸣、推送叮声 |
| 2.1–8.6s | 9 次画面撕裂（切片错位 + 红青线），卡片同时闪出“真相”（可选） | 电流声 |
| 4.6–8.9s | 红光环里出现人物，剪影里塞满“罪”的话，镜头渐晃；人物的“罪”随心跳加重 | 渐快心跳、上扬噪声 |
| 8.9–9.45s | 去色 → 金光斜斩（要**斩到贯穿意象**）→ 画面沿刀痕劈开 → 闪白 | 斩击、撕裂、冲击轰鸣 |

| 时间 | 第二幕：德（金） | 声音 |
|---|---|---|
| 9.45–12s | 罪字碎片飞散、三重冲击波，金色人物出现，“罪”的痕迹消散 | 碎片叮当、气流、和弦起 |
| 11.9–24s | 标题卡：标签框 / 设问句（关键词用「」金字）/ 超大金色标题 / 斜体拉丁文 | 钟声、慢鼓、和声、光波轻响 |

## 三、代码在哪、怎么起一个新主题

最新引擎：`works/2026-10-22_virtue-honesty/src/`（整个 `src/` 复制到新的 `works/<日期>_virtue-<id>/` 再改）。

| 文件 | 作用 | 新主题要改吗 |
|---|---|---|
| `gen_stories.py` | 全部文案：卡片（说出口的话 / 真相）、漂浮字、罪字、设问、标题、拉丁文、标签、光环刻字、强调色、调号、`figure` 人物名 | **改** |
| `figures/<人物>.js` | 人物两幕的画法 + 转场斩到哪里 + 人物专属音效时间点（`FIG`） | **新写一个** |
| `index.html` | 引擎：卡片、漂浮字、文字填充、背景、光环、标题卡、`renderAt(t)` 主循环 | 一般不动 |
| `fx.js` | 通用特效库（见第六节） | 一般不动，新特效写成通用的再加进来 |
| `audio.py` | 通用配乐音效 + `EVENT_SYNTH` 人物音效 | 新音效种类加进 `EVENT_SYNTH` |
| `render.js` / `build.sh` | 静帧、分段渲染、导出音效事件、混音、缩略拼图 | 不动 |

字体不入库：`npm pack @expo-google-fonts/noto-serif-sc @expo-google-fonts/noto-sans-sc @expo-google-fonts/cinzel`，
把 NotoSerifSC_900Black / NotoSerifSC_700Bold / NotoSansSC_700Bold / NotoSansSC_400Regular / Cinzel_400Regular / Cinzel_700Bold 放进 `src/fonts/`。

## 四、人物：按主题设计（最重要的一步）

**原则**

1. 选一个**一眼就能看懂这个美德**的形象，大众熟悉优先（诚实 → 说谎鼻子变长的提线木偶，人人都懂）。
2. 两幕是**同一个角色的两面**：第一幕是“罪”的样子，第二幕是“德”的样子，中间有一个**贯穿意象**。
3. 金光斜斩要**斩到这个意象**（诚实：斩断提线；其他主题可以是斩断锁链、劈开面具、斩断绳结），
   斩完之后在第二幕让“罪”的痕迹当着观众的面消散（诚实：长鼻子缩回、木关节散掉、断线飘落化成光）。
4. 第二幕人物要端庄、像雕像，手里或胸前有一个发光的东西承接主题（诚实：手按胸口，掌心透出光）。

**已经用过的人物**（别重复）：勇气 = 持剑骑士（参考片）；节制 = 持壶女神；正义 = 蒙眼持天平；明智 = 手镜 + 油灯；
信念 = 圣杯；希望 = 锚；仁爱 = 燃烧的心；天使篇六支（贞洁、慷慨、勤勉、忍耐、宽容、谦卑）= 金色天使；
诚实 = 提线木偶 → 真正的少年（`figures/puppet.js`）。

**以后可以用的点子**（只是起点，按用户的主题再想）：

| 主题 | 第一幕（罪） | 贯穿意象 / 斩到什么 | 第二幕（德） |
|---|---|---|---|
| 守信 | 撕碎的合同、“下次一定”，人被一堆空头支票淹没 | 斩开缠在手上的谎话纸条 | 古人手扶一根立木（立木为信），木上亮起一个“信”字印 |
| 自律 | 被手机、闹钟、外卖锁链缠住的人 | 斩断锁链 | 清晨的奔跑者 / 拉满弓的射手 |
| 坚持 | 推石上山一次次滚下（西西弗斯） | 斩开压在背上的巨石 | 愚公 / 滴水穿石：石上出现被滴穿的光孔 |
| 感恩 | 只会伸手要的手，四周都是“理所当然” | 斩断伸出的手上的绳 | 捧灯的人，背后亮起许多小灯（帮过你的人） |
| 宽恕 | 攥着荆棘 / 绳结的拳头，越攥越流血 | 斩开绳结 | 摊开手掌放飞白鸽 |
| 专注 | 被无数弹窗拉扯的眼睛 | 斩断拉扯的线 | 闭目冥想或张弓瞄准，弓弦上一点光 |

**画法要点（Canvas 线描）**

- 构图固定：人物**面朝左、站在画面右侧**，头部约在 x 1260–1450、y 250–460；光环中心 `HC = [1330, 430]`、半径 `HR = 345`；
  画面左侧 x < 900 留给标题卡。头像式半身构图（头 + 肩 + 上身到画面底边），不要全身小人。
- 轮廓用 `catmull(点列, true)` 描闭合剪影；五官单独描线：眼（上下眼睑 + 瞳孔点 + 强调色高光）、眉、鼻翼、嘴角、耳朵。
  **一定要画下颌线和颈部线**，否则脖子看起来很粗。
- **头发别画成一大团**（会像头巾或头盔）：贴着头骨画一个椭圆，外缘一圈小鼓包，里面画小螺旋发卷，像古典雕像。
- **手臂别画成两根管子**：用斗篷 / 袖子盖住上臂，只露前臂和手；手用 catmull 点列 + 两三条指缝线。
- 第一幕人物：剪影里用 `fillWithText(path, t, reveal, a)` 塞满罪的话，轮廓用 `redStroke`；要有一个随心跳变化的“罪”（诚实：鼻子随心跳一截截变长、冒出枝叶）。
- 第二幕人物：深色填充 + `glowStroke` 金线；`accentFill / accentStroke`（强调色）只用在一两处（瞳孔、光源、扣子）。
- 检查画得像不像：出静帧后**用 ffmpeg crop 把头部放大看**，缩略图看不出问题。

## 五、人物文件接口（`figures/<人物>.js` 里定义 `const FIG`）

| 成员 | 调用时机 | 说明 |
|---|---|---|
| `FIG.SLASH = {ax, ay, bx, by}` | 转场 | 斜斩从 A 到 B（0.3 秒画完），劈开画面也沿这条线。要正好横穿贯穿意象 |
| `FIG.cracks` | 第一幕 | 设成 `false` 关掉通用红裂纹（会和细线类意象混淆） |
| `FIG.early(t)` | 第一幕，人物出现前 | 黑暗中的眼睛、淡淡的轮廓 |
| `FIG.red(t, k)` | 第一幕，画在漂浮字和卡片**下面** | 人物主体，`k` 是出现进度 0→1 |
| `FIG.redTop(t, k)` | 第一幕，画在卡片**上面** | 需要压在卡片上的部分（诚实：长鼻子、提线、控制木架、眼睛的光） |
| `FIG.gold(t, k)` | 第二幕 | 金色人物 + 它的光源 + “罪”的痕迹消散 |
| `FIG.burst(t)` | 第二幕开头约 4 秒 | 人物专属的碎片（诚实：断线飘落、木架断成两截飞走、木屑） |
| `FIG.flare(t)` | 第二幕，可选 | 光源处的镜头光晕 |
| `FIG.events` | 出片时导出 | `[{t, kind, ...}]`，`render.js events` 写成 json 给 `audio.py`，按 `kind` 合成人物专属音效 |

规则：一切都是 `t` 的纯函数（`renderAt(t)` 无状态，才能 4 路并行渲染）；姿态写成 `pose(t)`，挂点、斩断时刻这类派生数据在加载时算一次。
注意 `const FIG` 不是 `window` 的属性，在 `page.evaluate` 里要用 `typeof FIG`。

## 六、通用特效库（`fx.js`）

第一幕：`embers` 火星、`cracks` 红裂纹、`heartbeats` + `pulse` 心跳暗角、`GLITCH` + `glitch` 画面撕裂、`truthFlip` 卡片闪真相（故事里 `truthFlip: true` 才开）、`scanlines`。
转场：`slashLine` 金光斜斩、`splitFrame` 整帧劈开错开（整体放大 1.2 防露边）、`shards` 罪字碎片、`shockwaves` 三重冲击波。
第二幕：`godRays` 上帝光、`orbitSparks` 绕环光点、`goldMotes` 上升金尘、`flare` 镜头光晕、`titleSparks` 标题迸光、`lightSweep` 斜向扫光。
全片：`bokeh` 前景虚化光斑（第二幕避开标题区）、`vignette`、`grain` 胶片颗粒。

## 七、声音

- `audio.py` 通用部分按故事时间轴合成：嗡鸣、卡片叮声、心跳（和 `fx.js` 的 `heartbeats` 同公式）、撕裂电流声（同 `GLITCH`）、
  上扬噪声、斩击、劈开撕裂、闪白冲击、碎片叮当、气流、和弦 + 高八度和声（调号 `key`）、标题钟声、慢鼓、光源低鸣、光波轻响。
- 人物专属：`EVENT_SYNTH` 里已有 `creak`（木头吱呀 + 咚）、`knock`（木关节咔嗒）、`twang`（拨弦断线，Karplus-Strong）、
  `clatter`（木块落地）、`retract`（往上走的晶亮音）。新人物需要的声音就加新 `kind`。

## 八、出片流程

1. `cd src && python3 gen_stories.py`
2. 静帧：`NODE_PATH=$(npm root -g) VIRTUE=<id> node render.js still out 1.2 5.6 8.8 9.2 9.6 10.4 13.4 20`，拼图看整体，再 crop 头部放大看细节。
3. 全片：在作品目录下 `bash src/build.sh <id> .`（4 核约 9 分钟，25 秒成片约 55–60MB），放后台跑。
4. 自检：`ffprobe` 看 1920×1080 / 30fps / 25.2s；看 `thumbs.jpg`；`ebur128` 看响度约 −16 LUFS、真峰值 ≤ −1.5 dB。
5. 按仓库 `CLAUDE.md` 存档：成片 + `thumbs.jpg` + `src/` + `README.md` + `captions.md`（发布标题、正文、话题，话题里也不写七美德）存进 `works/`，
   更新 `works/README.md`，提交并推送到当前工作分支。

## 九、踩过的坑

- 光环刻字要按整数遍均分一圈（`step = 2π / (遍数 × 字数)`），否则短句会绕不满或断在半个单词。
- 用 Python 批量替换代码时，别把注释插进单行代码中间，会把后半行一起注释掉。
- 第一幕的东西如果要盖在卡片上，放进 `FIG.redTop`；卡片会被人物附近的推力推开，但长条形的东西（长鼻子）会伸进卡片区。
- 斩断的时刻用线段和 `SLASH` 求交，按斜斩的缓动反推出 `tc`，画面、人物垮下、断线声三者才能对齐。
