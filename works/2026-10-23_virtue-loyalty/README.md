# 美德 · 忠诚（FIDELITAS · LOYALTY）—— 伸手够银币的骑士 → 持剑宣誓的金甲骑士

照「诚实」「自律」「自由」的两幕反转结构做的单支，25.2 秒，1920×1080 30fps，无配音。**画面上不出现“七美德”**：
标签是「美德 · 至死不渝」，光环刻字 `SEMPER FIDELIS · FIDELITAS`（永远忠诚）。人物是用户点名的**骑士**，要求“动态、盔甲、剑、特效”。

## 代码（`src/`）

引擎沿用 `2026-10-22_virtue-freedom/src/`，`index.html` 只加了一个通用钩子 `FIG.shake(t)`（人物动作带的镜头震，可选）。

- `figures/knight.js`：本片人物——
  - 闭面盔（鸟喙状面甲、眼缝、透气孔、护颚、护喉甲片、盔脊、后颈护盘、九根随风飘的长羽）、倒三角的胸甲（领口卷边、中脊、尖拱腹甲、四层甲裙、蚀刻菱形纹）、盾形纹章 + 心、往右飘的披风；
  - 手臂按骨骼画：上臂甲 / 前臂甲 / 喇叭口护腕在各自的局部坐标里，肩甲（顶片 + 三层甲片）跟着上臂转一点，护肘是杯形肘盘 + 扇形翼；
  - 剑：梨形剑首、缠绳握把、十字护手 + 宝石、剑身（剑脊、血槽铭文），铁手套画在剑的坐标里、手腕点 `WR_X / WR_Y`；
  - 剑姿 `POSE`：给出握把位置 `H`、剑的朝向 `sa`、手腕在哪一侧 `side`、肘尖大概方向 `hint`，加载时解 IK 得到上臂 / 前臂角度；`KEYS` 是时间表，改剑姿顺序或节奏只动这两处；
  - 第一幕：吊着的钱袋（斩断时刻按斜斩缓动反推 `tc`）、漏下的银币、银币读数、纹章裂纹；第二幕：剑长出来、光弧、三种定格特效（`hitFX`）、金币四散、心跳的纹章；音效时间点 `FIG.events`
- `gen_stories.py`：全部文案 → `stories/loyalty.js`
- `audio.py`：新增人物音效 `coin / armorcrack / coinburst / summon / swing / oath / thunder / plant / heartcalm`（`mixs()` 叠长短不一的声音）

重新出片：在 `src/` 下 `python3 gen_stories.py`，再在本目录 `bash src/build.sh loyalty .`（4 核约 3 分钟）。
静帧预览：`NODE_PATH=$(npm root -g) VIRTUE=loyalty node src/render.js still out 2.4 7.6 9.15 10.2 11.4 13.0 15.45 18`。

字体不入库：`npm pack @expo-google-fonts/noto-serif-sc @expo-google-fonts/noto-sans-sc @expo-google-fonts/cinzel`，
把 NotoSerifSC_900Black / NotoSerifSC_700Bold / NotoSansSC_700Bold / NotoSansSC_400Regular / Cinzel_400Regular / Cinzel_700Bold 放进 `src/fonts/`。
